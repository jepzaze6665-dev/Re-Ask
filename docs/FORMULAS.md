## 1. เลเวล & EXP
| ค่า | สูตร | หน่วย / ช่วง |
|---|---|---|
| EXP ที่ต้องใช้ไปเลเวลถัดไป | `EXP_next(L) = floor(A + B × L^p)` | Base: A=100 B=20 p=1.8 · Job: A=80 B=15 p=1.7 |
| เพดาน | Base Lv 100 · Job Lv = `jobs[job].jobLvMax` (50 ต่อขั้นอาชีพ) | ถึงเพดานแล้ว EXP ค้างที่ 0 |
| แต้มสเตตัสเมื่อขึ้นถึง L | `floor(L/5) + 3` | |
| แต้มสกิล | +1 ต่อ Job Lv | |
| ค่าแต้มเพิ่ม stat v→v+1 | `floor((v−1)/10) + 2` | stat สูงสุด 99 |
| ตาย | เสีย `floor(EXP_next(L) × 0.01)` | ไม่ลดเลเวล |

- `RO.applyExp` เป็นฟังก์ชันล้วน: รับ EXP ติดลบ = 0, ทศนิยมปัดลง, ขึ้นหลายเลเวลในครั้งเดียวได้
- รางวัลการฆ่า 1 ครั้งมี key `exp:<killId>` → เรียกซ้ำไม่ได้ EXP ซ้ำ
- **EXP ตามส่วนต่างเลเวล** (`rules.expLevelDiff`, ส่วนต่าง = เลเวลมอน − เลเวลผู้เล่น): ≥ +5 → 120% · ≥ −3 → 100% · ≥ −6 → 75% · ≥ −10 → 40% · ≥ −15 → 15% · ต่ำกว่านั้น 5% — ใช้กับ EXP มอนและ EXP รางวัลจบประตูมิติ (เทียบเลเวลบอส + lvBonus)
- **Job EXP เฉพาะอาชีพ**: `jobs[job].jobExp` (โนวิซ A=30 B=8 p=1.5 — เร็วกว่าอาชีพอื่น)

## 2. สเตตัสย่อย (`RO.derive`)
| ค่า | สูตร |
|---|---|
| ATK สเตตัส | `STR + floor(STR/10)² + floor(DEX/5) + floor(LUK/5)` |
| ATK อาวุธ | `weapon.atk + bonus.atk` |
| DEF | `DEF อุปกรณ์ + floor(VIT × vitToDef)` (vitToDef = 0.5) · มอน: `def + floor(vit × 0.5)` |
| HIT / FLEE | `BaseLv + DEX + bonus` / `BaseLv + AGI + bonus` |
| CRIT (%) | `1 + floor(LUK × 0.3) + bonus` |
| หลบสมบูรณ์ (%) | `1 + floor(LUK/10)` (เฉพาะผู้เล่น) |
| MaxHP | `floor((hp.base + L×hp.perLv + L²×hp.curve) × (1 + VIT/100)) + bonus.hp` |
| MaxSP | `floor((sp.base + L×sp.perLv) × (1 + INT/100)) + bonus.sp` |
| รอบตี (วินาที) | `max(minInterval, base × (1 − min(maxReduction, AGI×0.004 + DEX×0.001 + aspd%/100)))` · base = `jobs[job].attackInterval[wtype]` · minInterval 0.30 · maxReduction 0.60 |

## 3. ดาเมจกายภาพ (`RO.physical`) — ลำดับการคำนวณ
1. **คริ**: สุ่ม `< CRIT − LUKเป้า × 0.2` (%) → ถ้าคริ ข้ามข้อ 2–3 (ทะลุการหลบ)
2. **หลบสมบูรณ์**: สุ่ม `< pdodge` (%) → MISS (LUCKY)
3. **โอกาสโดน**: `HitChance = clamp(0.95 + 0.005 × (HIT − FLEE), 0.50, 1.00)` → สุ่ม ≥ HitChance = MISS · สกิลที่ `ignoreFlee` ข้ามข้อ 2–3
4. **ATK**: ผู้เล่น = `ATKสเตตัส + ATKอาวุธ × U(1−0.05, 1+0.05)` (คริ = ค่าสูงสุด) · มอน = `U(atkMin, atkMax)` (คริ = atkMax)
5. **ตัวคูณ**: `ธาตุ = elementTable[ธาตุโจมตี][ธาตุเป้า]/100` · `ตัวคูณรวม = ขนาด × (1+%ขนาด) × (1+%เผ่า) × (1+%ธาตุเป้า) × (คริ ? 1.4 : 1)`
6. **Final** = `max(1, floor(ATK × skill%/100 × 100/(100 + DEF) × ธาตุ × ตัวคูณรวม))`
   - **ยกเว้น** ธาตุ = 0 (ภูมิคุ้มกัน) → ดาเมจ 0
   - ปัดลงครั้งเดียวตอนท้าย · ยังไม่มีเพดานดาเมจ (จะเพิ่มเมื่อมี PvP)

ธาตุโจมตี: สกิลที่กำหนด `element` > ธาตุอาวุธ > neutral

| อินพุต | หน่วย / ช่วงที่ถูกต้อง |
|---|---|
| ATK, DEF | จำนวนเต็ม ≥ 0 (DEF ติดลบถูกตัดเป็น 0) |
| skill% | 100 = ตีปกติ (≥ 0) |
| HIT, FLEE | จำนวนเต็ม (ไม่จำกัด เพราะถูก clamp ที่โอกาสโดน) |
| CRIT, pdodge | % 0–100 |
| ตัวคูณธาตุ | 0–1.75 จากตาราง 10×10 |

## 6. เงินและไอเทม (`INV.apply`)
- **ItemDefinition** (`items.json`) แยกจาก **ItemInstance** `{uid, id, qty, eq, sockets}` · uid ไม่ซ้ำในตัวละคร
- ยา/วัตถุดิบ (`use`/`etc`) ซ้อนกอง · อุปกรณ์ = 1 instance ต่อชิ้น
- ทุกการเปลี่ยน zeny/ไอเทมผ่าน `INV.apply(db, inv, {key, reason, zeny, add, remove})` เท่านั้น:
  - **idempotent**: key เคยใช้แล้ว → `{ok:true, dup:true}` ไม่ทำซ้ำ
  - **atomic**: ตรวจทั้งหมดก่อน (เงินไม่ติดลบ, ไม่เกิน 2e9, จำนวนเป็นจำนวนเต็ม > 0, มีของพอ, ของที่สวมห้ามเอาออก, น้ำหนัก) ผิดข้อเดียว = ไม่เปลี่ยนอะไรเลย
  - **log**: เก็บ ledger 300 รายการล่าสุด, key ที่ใช้แล้ว 1000 รายการล่าสุด
- สวม/ถอด = ย้ายที่ภายในเจ้าของเดิม (ไม่ผ่าน ledger) · อาวุธสองมือถอดโล่อัตโนมัติ · ต้องผ่าน lvReq
- **ตอนออนไลน์**: `INV.apply` ย้ายไปรันบนเซิร์ฟเวอร์ใน transaction ของ DB · ledger → ตาราง ItemTransaction/CurrencyTransaction · key → unique constraint

## 9. สกิล (`shared/skills.js`) & สถานะ (`shared/status.js`)
- ข้อมูล: `data/db/skills.json` (มี `v` = เวอร์ชันของสกิล), `data/db/statuses.json`
- ค่าตามเลเวล: ตัวเลข | array (index = Lv−1) | `{base, perLv}` = base + perLv × (Lv−1)
- **เรียน**: ต้องอยู่ในสายอาชีพ (สกิลอาชีพก่อนหน้าสืบทอด) · แต้มสกิล ≥ 1 · ไม่เกิน maxLv · ผ่าน `requires`
- **ร่าย** (ลำดับตรวจ): เรียนแล้ว → ไม่ติด cantCast/cantAct → คูลดาวน์หมด (`now ≥ cds[id]`) → อาวุธตรง `weapon` → SP พอ
  - เป้าศัตรู: เดินเข้าระยะ `range + 20 × ขนาดมอน` ก่อน · เวลาร่าย > 0 = แถบร่าย · `interruptible` = โดนตี/เดิน/ติดสถานะแล้วถูกขัด (เว้นมีบัฟ endure)
  - สำเร็จ: หัก SP → ตั้งคูลดาวน์ → `resolve` ทำ effects ตามลำดับ
- **effects**: `damage` (pct, element, hitBonus บวกเข้า HIT, radius = AoE วัดแบบวงรี y×1.4) · `damage_seq` (หลายจังหวะตาม event ของท่า) · `heal` · `status` (chance %) · `knockback` (เฉพาะตัวที่โดนจาก damage ก่อนหน้า) · `passive` (bonus เข้า RO.derive เมื่อถืออาวุธตรง)
- **สถานะ**: ติดซ้ำ = ต่อเวลาเป็นค่าที่ยาวกว่า ใช้ mods ใหม่ (ไม่ซ้อน) · mods รวมแบบบวก · `atkPct`/`defPct` คูณ ATK/DEF · DoT = `max(min, floor(MaxHP × pct%))` ทุก tick วินาที
- **เปลี่ยนอาชีพ**: `jobs[to].parent = อาชีพปัจจุบัน` · Job Lv ถึง `advance.jobLv` · ฆ่าครบหลังรับบททดสอบ · มีไอเทมครบ → ใช้ไอเทม + รับรางวัลในธุรกรรมเดียว (key `job:<nonce>:<to>`) → Job Lv 1 (แต้มสกิลที่เหลือติดตัวไป)
- **อาวุธตามอาชีพ**: ชนิดอาวุธต้องอยู่ใน `jobs[job].attackInterval`
- **รีเซ็ต**: ศิลาลบสเตตัส = ลด stat ถึงค่าเริ่มต้นแล้วคืนแต้มตามราคาจริง · ศิลาลบสกิล = คืนแต้มทุกเลเวล

## 10. เงาอสูร (`shared/shadow.js`, `data/db/shadows.json`)
- ไอเทมเงาสร้างอัตโนมัติจาก shadows.json เป็น `shadow:<id>` (ไม่ซ้อนกอง · แต่ละชิ้นมี `star`, `alt`)
- **ดรอป** (ต่อการฆ่า 1 ครั้ง): สุ่ม `< rate × (1 + LUK × 0.01)` % → ดาว = สุ่มถ่วงน้ำหนัก `[60,25,10,4,1]` → แปรธาตุ 5% · ไม่มี pity
- **ผนึก**: เงาลงได้เฉพาะช่องชนิดเดียวกัน (head = หมวกทุกชั้น, acc = เครื่องประดับทั้ง 2) และช่องว่าง → เงาออกจากกระเป๋า (ธุรกรรม key เดียว)
- **โบนัส** = ค่าใน `seal` × `stars.mult[ดาว−1]` (1.0/1.25/1.5/1.75/2.0) · ปัดทศนิยม 2 ตำแหน่ง · ผลพิเศษ (ตีติดสถานะ, สะท้อนดาเมจ, ฆ่าแล้วฟื้น HP) คิดเฉพาะของที่สวมอยู่
- **ถอด**: จ่าย `zenyByStar[ดาว−1]` (บอส ×5) · แตก 15% → เงาหาย · ไม่แตก → กลับกระเป๋า · เงินไม่พอ = ไม่เปลี่ยนอะไร
- **รวม**: เงาชนิดเดียวกันดาวเท่ากัน 2 ชิ้น → สำเร็จ `successByStar` (70/50/30/15%) ได้ดาว+1 · ล้มเหลวเหลือ 1 ชิ้น · แปรธาตุติดไปถ้ามีชิ้นใดเป็น
- **เรียก** (ปิดอยู่ — `rules.summonEnabled: false`): ได้ทีละ 1 ตัว (ไอเทมถูกล็อกระหว่างเรียก) · พยาบาล = ฮีล `MaxHP × healPct × mult` ทุก interval · นักล่า = ตีเป้าของผู้เล่น 60% × mult · แทงค์ = มอนในรัศมี 350 ตีมันแทน (HP = MaxHP ผู้เล่น × hpMult × mult × 0.6) · ทุบพื้น = AoE `pct × mult / 2` + สตัน · สลายแล้วกลับมาใน 20 วิ

## 13. ร้าน NPC / โรงแรม / คลัง (`shared/shop.js`, `data/db/shops.json`)
- ซื้อ = `items[id].price × จำนวน` (1–999) · ร้านต้องมีของชิ้นนั้นในรายการ · ตรวจน้ำหนัก
- ขาย = `floor(price × 0.5)` · ราคา 0 / ของที่สวม / ของที่มีเงาผนึก ขายไม่ได้ · ทุกชิ้นในร้านขายคืนได้น้อยกว่าราคาซื้อ (กันปั๊มเงิน — มีเทสต์)
- โรงแรม: พัก 50 z = HP/SP เต็ม · เปิดคลัง 40 z ต่อครั้ง
- คลัง: 100 ช่อง · ย้ายของแบบ atomic สองฝั่ง (key บันทึกทั้งกระเป๋าและคลัง) · คุณสมบัติประจำชิ้นติดไปด้วย · ถอนต้องไม่เกินน้ำหนัก
- สถิติเศรษฐกิจ: `inv.stats.src / sink` = ยอดเงินเข้า/ออกสะสมตามหมวด (kill/zeny, shop, inn, refine, unseal, ...)

## 14. AI มอน (`shared/ai.js`, `rules.ai` + `mobs.json ai`)
- สถานะ: **idle** (เดินเล่นรอบจุดเกิด) → **chase** (ก้าวร้าวเห็นในระยะ detect 260 / โดนตี / โดนยั่ว / พวกเรียก) → **windup** ง้าง `windup` วินาที → ตี → chase …
  - **return**: เป้าไกลเกิน chase 520 หรือห่างจุดเกิดเกิน leash 700 → กลับจุดเกิด (เร็ว ×1.3) ถึงแล้วฟื้น HP เต็ม
  - **flee**: HP ต่ำกว่า `flee.hpPct` → หนี (ต้นอ่อนเงา 30%)
- **หลบได้**: ตอนมันง้างเสร็จ ถ้าผู้เล่นอยู่ไกลเกิน `ระยะตี × 1.25` = ไม่โดน (แสดง "หลบ!")
- **เรียกพวก** (`assist`): โดนตีแล้วมอนชนิดเดียวกันในรัศมี 250 ที่ว่างอยู่เข้ามาช่วย (เงาราก)
- **บอส**: เฟสตาม %HP (`phases`) — เข้าเฟสใหม่ได้ mods (ATK%/DEF%) + ชุดสกิลใหม่ · สกิลมีวงเตือนบนพื้น (`telegraph` วินาที) ออกจากวงทันก็ไม่โดน · ดาเมจสกิล = `pct` ของ ATK บอส ไม่มีพลาด/คริ
  - ราชาราก: 100% ทุบพื้น · 60% +เรียกต้นอ่อน 3 ตัว (ATK +20%) · 30% +แผ่นดินไหวรัศมีใหญ่ (ATK +40%, DEF −20%)

- ส่ง: หักของ + ให้ zeny/ไอเทมในธุรกรรมเดียว key `quest:<id>:<วันที่|once>` → ส่งซ้ำไม่ได้รางวัลซ้ำ · EXP ผ่านระบบ EXP ปกติ (key กันซ้ำ)

## 16. ดันเจี้ยนสุ่ม (`shared/dungeon.js`, `data/db/dungeons.json`)
- เข้าผ่าน **ประตูมิติ** (§17) · ทุกครั้งสุ่ม seed ใหม่ → `generate` สร้างขนาดแผนที่ หินกีดขวาง และกลุ่มมอน (seed เดียวกัน = แผนที่เดียวกัน)
- จุดเกิดฝั่งซ้าย · ห้องบอสฝั่งขวา · ไม่มีหินทับจุดเกิด/ห้องบอส · มอนไม่เกิดในรัศมี 420 จากจุดเกิดและไม่ทับหิน
- มอนแต่ละตัวมีโอกาสเป็น **ดุร้าย** (`elite.chance` %): HP × hpMult, ATK +atkPct%, EXP × expMult
- **ประตูบอสเปิด** เมื่อฆ่ามอนธรรมดาครบ `bossUnlockPct` % ของทั้งหมด → บอส (HP × boss.hpMult) เกิดที่ห้องบอส
- โค่นบอส = จบดัน → รางวัล (EXP, zeny สุ่มช่วง, ไอเทมตาม rate%) ผ่านธุรกรรม key `dungeon:<id>:<seed>:<เวลาเข้า>` ได้ครั้งเดียว → วาร์ป "กลับเมือง" ขึ้นที่ห้องบอส
- ออกก่อนได้ทุกเมื่อที่วาร์ป "ออกจากดัน" (เก็บของที่ดรอปได้ระหว่างทาง แต่ไม่ได้รางวัลจบดัน) · ตายในดัน = เกิดที่เมือง รอบนั้นจบ · มอนในดันไม่เกิดใหม่

## 17. ประตูมิติ (`shared/rift.js`, `data/db/rifts.json`)
- เกิดในแมพที่ตั้งไว้ (ตอนนี้ป่ารากมืด): ครั้งแรก 20 วิหลังเข้าแมพ แล้วทุก 180–300 วิ · พร้อมกันสูงสุด 2 ประตู · อายุ 600 วิ (กะพริบช่วง 30 วิสุดท้าย)
- ตำแหน่ง: นอกเขตปลอดภัย · ห่างผู้เล่น ≥ 350 · ห่างประตูอื่น ≥ 400
- สีสุ่มตามน้ำหนัก: น้ำเงิน C 55 · ม่วง B 28 · ทอง A 13 · แดง S 4 · เลเวลแนะนำ 12 / 23 / 40 / 48 (จูนจาก `tools/balance_sim.js`) · `lvBonus` +3 / +6 / +10 / +14
- เข้าได้อิสระ (กด F) — เลเวลต่ำกว่า `recLv` จะถามยืนยัน · ใช้ได้ครั้งเดียว · ไม่จับเวลา
- มอนในดัน: HP × `hpMult` · ATK +`atkPct`% · EXP × `expMult` · โอกาสเงาอสูร × `shadowMult` · มอนดุร้ายตาม `eliteChance` (คูณ/บวกซ้อนกับค่าดุร้ายของ template)
- บอส: HP × (template.boss.hpMult × bossHpMult × hpMult)
- รางวัลจบ = รางวัล template × `rewardMult` (EXP/zeny) + `extraItems` · ออกก่อน/ออกหลังจบ = กลับไปที่ตำแหน่งประตูเดิม

## 18. จำลองสมดุล (`tools/balance_sim.js`)
- `node tools/balance_sim.js [ชั่วโมง] [seed]` — บอทฟาร์มด้วยสูตรจริงจาก shared/ (เลือกมอนที่ได้ EXP/วินาทีดีสุด, แจกแต้ม STR/DEX/VIT/AGI, เรียนสกิลตามลำดับ, ซื้อยา, ขายของ, เข้าประตูมิติเมื่อเลเวลถึง, ไม่หลบท่าง้าง)
- `node tools/balance_sim.js rifts` — ใช้ตัวละครที่เซฟจากรอบฟาร์มล่าสุด ทดสอบอัตราตายของประตูแต่ละสีเร็วๆ (`LVS=10,20,30` กำหนดเลเวลที่ทดสอบ)
- ผลล่าสุด (30 ชม., seed 2): โนวิซ → นักดาบ 56 นาที · Lv 10 ที่ 1 ชม. 22 น. · Lv 25 ที่ 3 ชม. 49 น. · Lv 35 ที่ 16 ชม. · อัศวินดำ ~22 ชม. (Lv 37) · Lv 40 ที่ 28 ชม. — ช่วง Lv 25+ ช้าลงเพราะเนื้อหามีมอนถึง Lv 10 (+ ประตูมิติ) ต้องเพิ่มแมพ/มอนใหม่
