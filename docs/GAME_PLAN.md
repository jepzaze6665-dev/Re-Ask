# Re-Ask — แผนระบบ MMORPG

> แนวทาง: โครงระบบอาชีพ/บิลด์แบบ **Ragnarok Online** + ความรู้สึกการต่อสู้และ VFX แบบ **Night Camp** + ภาพสไตล์ chibi HD ของเราเอง
> เล่นบนเว็บก่อน → ห่อเป็น .exe (Electron/Tauri) ทีหลัง โค้ดชุดเดียว

---

## 0. แบ่งงาน 2 ที่
| ที่ | ทำอะไร |
|---|---|
| **สตูดิโอ** `สอน AI/` | ตัวละคร ชุด อาวุธ มอนสเตอร์ VFX ท่าทาง (Rig Lab, Pose Studio, Dark VFX Lab) → `export_game.py` |
| **เกม** `Re-Ask/` | ระบบเกม เซิร์ฟเวอร์ ข้อมูล (สเตตัส ไอเทม สกิล แมพ) UI |

กติกา: ของภาพ/อนิเมชันแก้ในสตูดิโอเท่านั้น · ตัวเลขเกม (ดาเมจ ดรอป) อยู่ในไฟล์ข้อมูลของเกม (`data/db/*.json`) ไม่ฝังในโค้ด

## 1. สถาปัตยกรรม (Server-authoritative)
```
 Browser client (Canvas)                Game Server (Node.js)                 DB
 ┌──────────────────────┐   WebSocket   ┌───────────────────────────┐   ┌──────────────┐
 │ render · input       │ ◄──────────► │ Gateway (login, char select)│   │ PostgreSQL   │
 │ prediction (เดิน)     │   20 tick/s  │ Map servers (1 process/แมพ) │──►│ บัญชี ตัวละคร │
 │ interpolation (คนอื่น) │              │ Instance (ดันเจี้ยนปาร์ตี้)   │   │ ไอเทม กิลด์   │
 │ VFX / ตัวเลข (ภาพล้วน) │              │ Chat · Party · Guild · Trade│   ├──────────────┤
 └──────────────────────┘              └───────────────────────────┘   │ Redis        │
                                                                         │ session ออนไลน์│
                                                                         └──────────────┘
```
- **เซิร์ฟเวอร์ตัดสินทุกอย่าง** (ดาเมจ ดรอป EXP ตำแหน่ง) — client ส่งแค่ "ตั้งใจจะทำ" (เดินไป x,y / ใช้สกิล id ใส่เป้า id) → กันโกง
- client **ทำนาย** การเดินของตัวเอง (ไม่หน่วง) และ **ไล่ตำแหน่ง** คนอื่นแบบนุ่ม (interpolation 100ms)
- **โค้ดสูตรร่วม** `shared/` (คำนวณดาเมจ สเตตัส) ใช้ทั้ง client (แสดงผล) และ server (ตัดสินจริง)
- เทคโนโลยีเสนอ: Node.js + `ws` (หรือ Colyseus) · PostgreSQL · Redis · ภาษา TypeScript
- Tick 20 ครั้ง/วิ · ส่งเฉพาะสิ่งที่อยู่ในระยะมองเห็น (AOI grid) ประหยัดเน็ต
- ขยาย: 1 แมพ = 1 process → คนเยอะเปิด **ช่อง (channel)** เพิ่ม

## 2. ตัวละคร & สเตตัส (แบบ RO)
**6 สเตตัสหลัก** ได้แต้มทุกเลเวล (เลเวลสูงได้มากขึ้น) แจกเองได้ → บิลด์หลากหลาย
| สเตตัส | ผล |
|---|---|
| STR | ATK กายภาพ, น้ำหนักแบก |
| AGI | ASPD (ความเร็วตี), FLEE หลบ |
| VIT | MaxHP, DEF ลดดาเมจ, ต้านติดสถานะ |
| INT | MATK, MaxSP, ร่ายเร็ว |
| DEX | HIT แม่น, ATK ระยะไกล, ร่ายเร็ว |
| LUK | คริ, หลบสมบูรณ์, ดรอป |

**สเตตัสย่อย** (คำนวณ): ATK, MATK, DEF, MDEF, HIT, FLEE, CRIT, ASPD, Cast time, MaxHP/SP
**เลเวล 2 แบบ**: Base Lv (สเตตัส) + Job Lv (แต้มสกิล) เหมือน RO
**รีเซ็ตสเตตัส/สกิล**: ไอเทมหายาก → ให้ลองบิลด์ใหม่ได้

## 3. ระบบอาชีพ (Job tree)
```
Novice (Lv 1-10)
 ├─ Swordman ──► Knight (อัศวินดำ ✓ มีแล้ว) ──► Lord Knight
 │            └► Crusader (ดาบ+โล่ ธาตุศักดิ์สิทธิ์)
 ├─ Mage ─────► Wizard (AOE ธาตุ) / Sage (สลับธาตุ)
 ├─ Archer ───► Hunter (ธนู+กับดัก+สัตว์) / Bard
 ├─ Thief ────► Assassin (มีดคู่ คริ) / Rogue
 ├─ Acolyte ──► Priest (ฮีล บัฟ) / Monk (หมัด คอมโบ)
 └─ Gunner ───► Sniper / Outlaw (ปืน — แบบ Vega/Rook ใน Night Camp)
```
- เปลี่ยนอาชีพที่ Job Lv 10 (อาชีพ 1) และ Job Lv 40+ (อาชีพ 2) ผ่าน **เควสต์ทดสอบ**
- **ทุกอาชีพใช้ rig เดียวกัน** → อาชีพ = ชุดเริ่มต้น + อาวุธ + ท่าโจมตี + ชุดสกิล (ดูแผนอาวุธหลายคลาสที่คุยไว้)
- **ต่อยอดจาก RO**: (1) สกิลเปลี่ยนรูป VFX ตามธาตุอาวุธ (2) "แขนงบิลด์" ภายในอาชีพ เช่น Knight สายเงา (ธาตุมืด, VFX ม่วง) vs สายเลือด (ดูดเลือด, VFX แดง) — ใช้ระบบเปลี่ยนสี VFX ที่มีแล้ว

## 4. สกิล
- **สกิลทรี**: แต่ละสกิลมีเลเวล 1-10 + เงื่อนไข (ต้องมีสกิล X Lv 5) ใช้แต้มจาก Job Lv
- ประเภท: Active (กด), Passive (ติดตัว), Toggle/Buff, Combo (ต่อจากสกิลอื่น)
- ข้อมูลสกิล = JSON: `{id, name, job, maxLv, sp[], cast[], cd[], range, target, element, damage: "ATK*(1+0.3*lv)", vfx:"swarm", clip:"สกิล: ฝูงอสูรเงา", requires}`
- **ภาพ/อนิเมชันผูกผ่านชื่อ** `vfx` + `clip` → สตูดิโอทำของ เกมแค่อ้างชื่อ

## 5. คอมแบต
- **การโจมตี: คลิกเป้า → ตีอัตโนมัติ** ตามรอบ ASPD (แบบ RO) · ท่าคอมโบ 3 จังหวะใช้วนเป็นท่าตี
- **สูตรของเราเอง (ไม่ลอก RO)**: Final = max(1, floor(ATK × สกิล% × 100/(100+DEF) × ธาตุ × ตัวคูณรวม(ขนาด/เผ่า/เงาอสูร))) · โอกาสโดน = clamp(0.95 + 0.005×(HIT−FLEE), 0.50, 1.00) · คริ ×1.4 · รอบตี = max(ขั้นต่ำ, ฐาน × (1 − ลดรอบตี)) · ตัวเลขทั้งหมดอยู่ใน rules.json
- **ตารางธาตุ 10×10**: Neutral, Water, Earth, Fire, Wind, Poison, Holy, Shadow, Ghost, Undead
- **ขนาด** (เล็ก/กลาง/ใหญ่) ส่งผลต่ออาวุธแต่ละชนิด — ทำให้การเลือกอาวุธมีความหมาย
- **สถานะผิดปกติ**: สตัน แช่แข็ง พิษ เลือดไหล หลับ เงียบ (ร่ายไม่ได้) ตาบอด
- game feel (มีแล้ว): hitstop, จอสั่น, ตัวเลข, TOTAL, ชื่อสกิล, ง้างก่อนโจมตี (ศัตรูต้องง้างให้หลบได้)
- ตัดสินบนเซิร์ฟเวอร์ · client เล่น VFX ทันทีที่กด (ไม่รอ) แล้วตัวเลขตามมาจากเซิร์ฟเวอร์

## 6. ไอเทม & อุปกรณ์
- ช่อง: อาวุธ, โล่/มือซ้าย, หมวก (บน/กลาง/ล่าง แบบ RO), เกราะ, ผ้าคลุม, รองเท้า, เครื่องประดับ ×2
- **ชุดแสดงผล = ชิ้นส่วน rig** (หลักที่ 3: แม่แบบเดียว) → หมวกใช้ระบบซ่อนผมที่มีแล้ว
- **ตีบวก (Refine) +1~+10**: เกิน +4 มีโอกาสพัง/ลดขั้น · +7 ขึ้นไปอาวุธเรือง (ใช้ระบบชั้นแสงเต้นที่มีแล้ว — ยิ่งบวกสูงยิ่งเต้นแรง)
- **เงาอสูร (Shadow Essence)** — แทนการ์ด RO · ลุ้นดรอปล้วน **ไม่มีระบบการันตี (pity)**
  - มอนแต่ละชนิดดรอปเงาของตัวเอง (ทั่วไป ~0.1–0.3%, บอส ~0.01–0.05%, ตั้งใน mobs.json) · LUK เพิ่มโอกาส
  - ตอนดรอปสุ่มคุณภาพ ★1–★5 + โอกาสน้อยได้ "เงาแปรธาตุ" (โบนัส/สีเปลี่ยนตามธาตุ) → ใบเดียวกันค่าไม่เท่ากัน
  - ใช้ได้ 2 แบบ: **ผนึก** ลงช่องอุปกรณ์ (โบนัสติดตัว) หรือ **เรียก** ออกมาสู้ข้างตัว 1 ตัว
  - **รวมเงา** ซ้ำเพื่อลุ้นอัปดาว (มีโอกาสล้มเหลว = ตัวดูดของออกจากระบบ)
  - **ถอดเงาได้แต่แพง**: จ่าย zeny ตามดาว (บอส ×5) + โอกาสเงาแตก 15% = ตัวดูดเงิน
  - **ช่องผนึก**: เงาแต่ละตัวลงได้เฉพาะชนิดช่องของมัน · ของสวมใส่ที่ดรอปสุ่มจำนวนช่อง 0–3 (50/35/12/3%) = ลุ้นอีกชั้น
  - ค่าทั้งหมดอยู่ใน `data/db/shadows.json`
- ระดับ: ธรรมดา / หายาก / ตำนาน (กรอบสี + แสงเรือง)
- น้ำหนักแบก (STR) · ของกิน/ยา · วัตถุดิบคราฟต์
- **เศรษฐกิจ**: ร้านผู้เล่น (Vending แบบ RO), เทรด, ร้าน NPC ซื้อขาย, ค่าธรรมเนียมตีบวก = ตัวดูดเงินออกจากระบบ

## 7. มอนสเตอร์
- ข้อมูล: `{id, name, lv, hp, atk, def, element, size, race, exp, jobExp, drops:[{item, rate}], card:{id, rate:0.01%}, ai, sprite/rig}`
- **AI**: เฉย/ก้าวร้าว/ขี้ตาม (Looter) / เรียกพวก / หนีเมื่อเลือดน้อย · บอสมีเฟส + ท่าง้างใหญ่ (วงเวทเตือนบนพื้น)
- **MVP / บอสสนาม**: เกิดตามเวลา ใครตีมากสุดได้รางวัล MVP (แบบ RO)
- ภาพ: มอนส์เล็ก = sprite sheet หรือ rig สัตว์ · บอส = rig + sprite VFX (ท่าใหญ่ใช้ sprite ตามที่ตกลง)

## 8. แมพ & โลก
- **เมือง** (ปลอดภัย, NPC, ร้าน, ที่ฝากของ, เปลี่ยนอาชีพ) → **ทุ่ง** (มอนส์ตามเลเวล) → **ดันเจี้ยน** (หลายชั้น)
- สร้างแมพแบบ Night Camp: **ชุดของประจำแมพ + ใบสั่ง JSON + กฎ + seed** (หลักที่ 10) — แมพเดิมทุกครั้งสำหรับเซิร์ฟเวอร์
- ใบสั่งแมพ: `{name, lvText, seed, W, H, biome, roads, landmarks, safe, spawns:[{mob, count, area}], warps:[{to, x, y}]}`
- เซิร์ฟเวอร์ใช้ข้อมูลเดียวกันสำหรับ **ชน/เดินได้** (navmesh/grid)
- แสง: normal map + ช่วงเวลา (เช้า-เที่ยง-เย็น-คืน) ตามคลิป — กลางคืนมอนส์บางตัวแรงขึ้น
- **หอคอย/รากต้นไม้มืด 100 ชั้น** (แบบคลิป Night Camp): ลงเดี่ยวหรือปาร์ตี้ 2-4 · บอสทุก 10 ชั้น · ตารางอันดับรายฤดูกาล

## 9. สังคม
- **ปาร์ตี้** (สูงสุด 4-6): แบ่ง EXP (เท่ากัน/ตามดาเมจ), แบ่งของ (สลับ/สุ่ม/ใครเก็บได้), หน้าต่าง HP สมาชิก, ห้องดันเจี้ยนส่วนตัว (instance)
- **กิลด์**: ยศ, คลังกิลด์, สัญลักษณ์บนหัว, **วอร์กิลด์ยึดปราสาท (WoE)** แบบ RO — เป้าหมายปลายเกม
- แชท: รอบตัว / ปาร์ตี้ / กิลด์ / กระซิบ / โลก · อีโมต
- เพื่อน · บล็อก · เทรดปลอดภัย (ยืนยัน 2 ฝ่าย)

## 10. เควสต์ & ความก้าวหน้า
- เควสต์หลัก (เนื้อเรื่อง), เควสต์เปลี่ยนอาชีพ, เควสต์รายวัน, ล่าบอส

## 13. สิ่งที่ต้องตัดสินใจ
1. เซิร์ฟเวอร์: เขียนเอง (`ws`) หรือใช้ Colyseus (มีห้อง/ซิงก์ให้แล้ว)
2. โฮสต์: เครื่องตัวเองก่อน → VPS (เช่น DigitalOcean/Hetzner) ตอนทดสอบหลายคน
3. ความยาก/ความโหดแบบ RO ดั้งเดิม (ตายเสีย EXP, เงาอสูรหายาก) หรือเบาลงแบบเกมมือถือ
4. รายได้ (ถ้ามี): ชุดแฟชั่นอย่างเดียว (ไม่ pay-to-win) แนะนำ

## 14. การตัดสินใจ (2026-10-16)
1. การต่อสู้ = คลิกเป้า ตีอัตโนมัติ (แบบ RO)
2. ใช้สูตรของเราเองตามข้อ 5 (Base Lv cap 100 · EXP_next(L) = 100 + 20 × L^1.8 · Job Lv cap 50 ต่อขั้นอาชีพ)
3. **ทำ offline ให้ดีก่อน** ค่อยทำเซิร์ฟเวอร์ แต่ไอเทม/เงิน/ดาเมจต้องพร้อมย้ายขึ้นออนไลน์:
   ฟังก์ชันล้วนใน shared/ + สุ่มแบบ seed · ไอเทมมี instance id แยกจาก definition · รับ/จ่ายเงินและของผ่านจุดเดียว มี idempotency key + log
4. JS + JSDoc ตรวจด้วย `tsc --noEmit` (ยังไม่ต้อง build) · เทสต์ `node:test` · เซิร์ฟเวอร์ภายหลังใช้ TypeScript + SQLite (→ PostgreSQL ตอนขึ้น VPS)
5. การ์ด → เงาอสูร (ลุ้นดรอป ไม่มี pity, ถอดได้แต่แพง, อุปกรณ์สุ่มช่อง 0–3) + สมุดล่า
6. มาตรฐานทุกเฟส: ทำเวอร์ชันเล็กสุดที่ครบ → เทสต์ผ่าน → อัปเดตเอกสาร → สรุปสิ่งที่ใช้ได้/ข้อจำกัด/ขั้นต่อไป
