## P2 อาชีพ & สกิล
- ระบบสกิล data-driven: active/passive/toggle · เป้าเดียว/ตัวเอง/พื้นที่ · เวลาร่าย + โดนขัด · คูลดาวน์ · SP · สกิลต้องมีสกิลก่อนหน้า
- บัฟ/ดีบัฟ/สถานะผิดปกติ (สตัน ติดราก พิษ ติดไฟ ...) ใช้ร่วมกับเงาอสูรภายหลัง
- สายอาชีพ Novice → Swordman → Knight + เควสต์เปลี่ยนอาชีพ (NPC ในเมือง)
- หน้าต่างสกิลทรี + แถบปุ่มลัด · รีเซ็ตสเตตัส/สกิลด้วยไอเทม
- เทสต์: เงื่อนไขสกิล, คูลดาวน์, ร่ายโดนขัด, บัฟซ้อน
- **เล่นได้**: เริ่มเป็น Novice → เปลี่ยนอาชีพ → อัปสกิล 4–6 ตัว

## P3 เงาอสูร & ตีบวก
- ดรอปเงา (ลุ้นล้วน ไม่มี pity) + สุ่มดาว ★1–★5 + เงาแปรธาตุ
- ผนึกลงช่อง / ถอด (จ่ายแพง เสี่ยงแตก) / เรียกออกมาสู้ / รวมเงาลุ้นอัปดาว
- ตีบวก +1~+10 (เกิน +4 เสี่ยงพัง) · สมุดล่า (Codex)
- ทุกขั้นตอนผ่าน `INV.apply` (กันซ้ำ)
- **เล่นได้**: ฟาร์มลุ้นเงา สร้างบิลด์

## P4 ร้านค้า & เศรษฐกิจ NPC
- ร้าน NPC ซื้อ/ขาย, ที่ฝากของ (storage), ค่าธรรมเนียม = ตัวดูดเงิน
- สถิติเงินเข้า/ออก (source/sink) จาก ledger
- **เล่นได้**: ขายของดรอป ซื้อยา ฝากของ

## P5 PvE
- AI มอนแบบ state machine (เฉย/ก้าวร้าว/ตามฝูง/หนี/กลับจุดเกิด) + ท่าง้างให้หลบได้
- บอสหลายเฟส + วงเตือนบนพื้น · เควสต์ (ฆ่า/เก็บ/คุย) · ดันเจี้ยนสุ่ม (P5b)
- จำลองสมดุล: EXP/ชม., อัตราได้ของ, เงินเข้า/ออก
- **เล่นได้**: เนื้อเรื่องช่วงแรก + ดันเจี้ยน

## P6 เซิร์ฟเวอร์ & บัญชี
- Node.js + TypeScript + SQLite (→ PostgreSQL ตอนขึ้น VPS) · WebSocket
- บัญชี/ล็อกอิน, สร้าง/ลบ/เลือกตัวละคร, เซฟบนเซิร์ฟเวอร์
- ย้าย `shared/` + `INV.apply` + คอมแบต ไปตัดสินบนเซิร์ฟเวอร์ · client ส่งแค่คำขอ
- **เล่นได้**: ล็อกอินจากเครื่องไหนก็ได้ ตัวละครอยู่ครบ

## P7 ออนไลน์
- เห็นผู้เล่นอื่น, แชท, ปาร์ตี้ (แบ่ง EXP/ของ), เทรดยืนยัน 2 ฝ่าย, ร้านผู้เล่น/ตลาด
- **เล่นได้**: เล่นกับเพื่อน

## P8 กิลด์ & PvP
- กิลด์ (ยศ สิทธิ์ คลัง log), สนาม PvP, วอร์กิลด์ (Registration → Preparation → Active → Scoring → Ended → Rewards), อันดับฤดูกาล
- **เล่นได้**: ปลายเกม

## P9 Hardening & Live
- load test, monitoring, ทดสอบการกู้คืน, กันโกง, .exe (Electron/Tauri), มือถือ
